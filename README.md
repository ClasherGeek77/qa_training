This repository contains the training collateral, assignments, and test cases for Web UI Test Automation. Developed and utilized extensively during QA mentorship batches at organizations such as **DOKU**, aiming to upskill SDETs.

## 🎯 Objective
To create a hands-on learning environment where QA professionals can graduate from basic record-and-playback to writing maintainable, scalable, and object-oriented test automation scripts for web applications.

## 📚 Curriculum Highlights
1. **DOM Mastery**: Understanding HTML structure, finding brittle locators, and crafting resilient XPaths and CSS Selectors.
2. **Page Object Model (POM)**: Structuring code to separate test logic from page locators, reducing maintenance overhead.
3. **Synchronization**: Mastering implicit, explicit, and fluent waits to combat flakiness in dynamic single-page applications (SPAs).
4. **Cross-Browser Execution**: Running tests across different environments.
5. **Final Matrix**: A capstone project testing an e-commerce flow from login to checkout.

## 🎓 Mentorship Approach
The exercises in this repo are designed to fail—teaching students how to debug, read stack traces, and implement robust error handling rather than just "happy path" testing.
